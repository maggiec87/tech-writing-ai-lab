AI Engineering focuses on the technical knowledge and engineering practices required to build, integrate, test, and operate AI-powered applications.

With the development of large language models and generative AI, application development increasingly involves model APIs, prompt design, retrieval systems, AI agents, evaluation, and production monitoring.

This area explores how these components work and how to combine them into practical, reliable applications.

## What This Area Covers

- **LLM Fundamentals:** Understanding large language models, tokens, context windows, inference, and model capabilities.
- **Prompt Engineering:** Designing instructions, context, and output formats to improve model behavior.
- **LLM API Integration:** Connecting applications to model providers and managing requests, responses, and errors.
- **Retrieval-Augmented Generation:** Connecting LLMs to external knowledge sources through retrieval and context injection.
- **AI Agents:** Building systems that use tools, manage tasks, and execute multi-step workflows.
- **Python for AI Applications:** Using Python to develop AI-powered applications and backend services.
- **AI Application Architecture:** Designing application components, data flows, and service integrations.
- **AI Testing and Evaluation:** Assessing accuracy, relevance, reliability, safety, and application behavior.
- **Observability:** Monitoring AI application performance, usage, latency, costs, and failures.
- **Deployment and Operations:** Preparing AI applications for practical use and ongoing maintenance.

## How This Area Is Organized

This topic is explored through three complementary approaches.

### Learn

Build a systematic understanding of LLM technologies, AI application components, and engineering methods.

Topics include:

- How Large Language Models Work
- Prompt Engineering
- LLM API Integration
- RAG vs. Fine-Tuning
- Building RAG Applications
- AI Agent Fundamentals
- Building AI Agents with Python
- AI Application Testing
- LLM Evaluation and Observability

Further topics may include AI application security, deployment architectures, model selection, and production optimization.

### Reviews

Study publicly documented AI architectures, engineering approaches, frameworks, and implementation examples.

These case studies examine how AI systems are designed and implemented, focusing on technical decisions, architecture, strengths, limitations, and lessons that can inform other projects.

Potential case study areas include:

- LLM Application Architecture
- RAG Implementation Approaches
- AI Agent Architecture
- LLM API Integration
- AI Evaluation Frameworks
- AI Application Testing
- Production AI Systems and Observability

Possible research subjects include public technical resources and projects from OpenAI, Anthropic, LangChain, LlamaIndex, LangGraph, Ragas, and other AI engineering organizations.

Reviews should be based on public technical documentation, engineering articles, source code, and reproducible observations. They should not assume access to proprietary internal architectures.

### Projects

Apply AI engineering concepts to working applications and technical experiments.

Potential project areas include:

- Building a Document Q&A Application with RAG
- Developing a Python-Based AI Assistant
- Creating an AI-Powered Research or Learning Tool
- Building an AI Agent with Tool Integration
- Implementing an LLM Evaluation Pipeline
- Developing an AI Application Testing Framework
- Comparing Different LLM Providers and Models

Projects may focus on learning a specific technology, solving a practical problem, reproducing a public implementation, or exploring alternative architectures.

## Learning Approach

AI Engineering is best learned by connecting technical concepts with working implementations.

The goal is to understand how AI components behave, how they interact, and how to build applications that are useful, testable, and reliable.

The learning process follows three connected activities:

1. **Learn** the underlying technologies, concepts, and engineering methods.
2. **Review** real-world architectures and implementations to understand technical choices and trade-offs.
3. **Build** practical applications, test their behavior, and improve their reliability.

This approach develops the ability to move from understanding AI technologies to implementing and evaluating AI-powered solutions.
