# Documentation Review Framework

## Review Checklist

- Is the intended audience clear?
- Does the page answer a real user question?
- Are prerequisites stated before the procedure?
- Are steps in the order users perform them?
- Are UI labels and technical terms consistent?
- Are expected results and recovery steps included?
- Can the content be scanned on desktop and mobile?

## Prioritization

Prioritize findings based on:

1. User impact
2. Frequency of the problem
3. Severity
4. Remediation effort

A review should include evidence, impact, and a practical recommendation.
