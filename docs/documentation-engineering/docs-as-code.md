# Docs as Code

Docs as Code means managing documentation with software-development
workflows such as Git, code review, automated checks, and continuous
deployment.

## Typical Workflow

1. Edit Markdown or MDX locally.
2. Preview the documentation site.
3. Commit changes to Git.
4. Review changes through a pull request.
5. Run automated checks and build.
6. Publish after changes are merged.

## Benefits

- Version control
- Change history
- Collaboration
- Reproducible builds
- Automated publishing
